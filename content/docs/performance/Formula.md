# Formula

## The Chaplin Performance Formula

The Chaplin formula template can be downloaded from basecamp: [Basecamp Formula](https://3.basecamp.com/3094795/buckets/24365546/uploads/5765194577) and after opening looks like the following:

![Overview formula][1]

In the blue fields it is possible to fill in the test scenario and the expected roles and scenarios.  
In the first row of orange fields you fill in the first test results.  
In the second row of the orange fields you fill in the test results from the second test.  

The grayed out area will go away if everything has been filled in correctly and shows the time and error differences with a conclusion whether the change should be accepted or not.  

In the settings it is possible to customize what should be included in the calculation. For example, when it is really important an error needs to be fixed, and it does not matter if the performance drops. The performance drop can be excluded in the formula with these settings.
